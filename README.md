# Paperplane PDF

A small, touch-friendly PDF reader and annotator. Open a PDF, draw with a finger, stylus, or mouse, add typed notes, and save an annotated copy.

## Start

Open `index.html` in a modern browser while connected to the internet. The app loads PDF.js and pdf-lib from CDNs. Your PDF is processed in the browser and is not uploaded.

## Use

- **Open PDF** to choose a document from your device.
- Use **Draw** to ink on the page, or **Text** and tap/click where you want to type. Press Enter or tap elsewhere to finish a text note.
- Use the page arrows and zoom controls to navigate.
- **Undo** removes the most recent mark or text note on the current page.
- **Save a copy** downloads a new `-annotated.pdf` file without changing your original.

Keyboard shortcuts: `Ctrl+O` opens a PDF, `Ctrl+S` saves an annotated copy, and the left/right arrow keys change pages.
